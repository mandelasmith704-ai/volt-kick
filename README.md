# VOLT KICK ⚽

Videojuego de fútbol arcade en desarrollo. **Prealfa web 0.4**.

## Jugar en el navegador

**https://mandelasmith704-ai.github.io/volt-kick/**

La versión actual es una demostración experimental en 3D para escritorio y pruebas en móvil. No es la versión comercial para App Store.

## Controles de computadora

- **WASD / flechas:** movimiento
- **Z:** pase
- **X:** disparo
- **C:** cambiar jugador
- **Shift:** correr
- **E:** superdisparo (si hay energía)

## Versiones

- 0.1: prototipo inicial 2D.
- 0.2: primera base tridimensional.
- 0.3: mejoras de cámara y controles.
- **0.4:** personajes diferenciados y saque para el equipo que recibió el gol.

## Publicación

La web se despliega automáticamente desde la rama `main` mediante GitHub Actions y Pages.

Proyecto en desarrollo: todos los nombres, gráficos y personajes son provisionales.
